# サポート（おしたくクエスト）

[English](support-en)

## よくある質問

**保護者設定を開きたい**
- 画面右上の ⚙️ アイコンを3秒間長押しすると開きます

**タスクを追加・編集したい**
- 保護者設定からタスクを追加・編集できます

**ファミリーパック（有料機能）とは？**
- 2人目以降のプロフィールを追加できる買い切り機能です
- 一度購入すれば永続的にご利用いただけます

**別の端末でファミリーパックを使いたい**
- 保護者設定の「購入を復元する」から復元できます（同一Apple IDが必要です）

**使われ方の記録の送信をやめたい**
- 保護者設定の「使われ方の記録を送る」をオフにしてください。詳しくは[プライバシーポリシー](privacy)をご覧ください

**アプリのデータを引き継ぎたい**
- 現在、端末間のデータ引き継ぎには対応しておりません
