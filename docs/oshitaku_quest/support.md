# サポート（おしたくクエスト）

## よくある質問

**タスクを追加・編集したい**
- 保護者設定（画面右上のアイコン）からタスクを追加・編集できます

**ファミリーパック（有料機能）とは？**
- 2人目以降のプロフィールを追加できる買い切り機能です（480円）
- 一度購入すれば永続的にご利用いただけます

**別の端末でファミリーパックを使いたい**
- 設定画面の「購入を復元する」から復元できます（同一Apple IDが必要です）

**アプリのデータを引き継ぎたい**
- 現在、端末間のデータ引き継ぎには対応しておりません
