# プライバシーポリシー（おしたくクエスト）
最終更新日：2026-07-03

本アプリ「おしたくクエスト」（以下「本アプリ」）は、以下の方針で個人情報等を取り扱います。

## 1. 収集する情報

### 端末内に保存される情報
- 子どもの名前・アイコン・テーマカラーなどのプロフィール情報
- 朝の支度タスクの設定内容（タスク名・順番・有効/無効状態）

これらの情報は端末内にのみ保存され、当方のサーバーへは送信されません。

### 外部サービスへ送信される情報

**RevenueCat（アプリ内課金管理）**  
ファミリーパック（買い切り）のご利用にあたり、RevenueCatを使用します。RevenueCatは購入管理の目的でデバイス識別子等を取得する場合があります。  
参考：<https://www.revenuecat.com/privacy/>

**Apple（App内課金）**  
ファミリーパックの決済はAppleのApp内課金を通じて行われます。支払い情報はAppleが管理し、当方は取得しません。  
参考：<https://www.apple.com/jp/legal/privacy/>

**PostHog（利用状況分析）**  
アプリの改善を目的として、PostHogを使用してアプリ内操作イベントを収集します。収集する情報は以下のとおりです。
- 画面表示・機能の利用状況（ペイウォール表示、購入・復元操作など）
- 匿名の利用統計

氏名・メールアドレス・位置情報など、個人を直接特定できる情報は送信しません。  
参考：<https://posthog.com/privacy>

## 2. 利用目的
- ファミリーパック（買い切り）のアプリ内課金管理
- アプリの機能改善・利用状況の分析（PostHog）

## 3. データの保管・削除
- アプリ内データ（プロフィール・タスク設定）は端末内に保存されます。アプリを削除すると端末内のデータも削除されます。
- 外部サービス（RevenueCat）が保持するデータについては、各サービスのプライバシーポリシーに従います。

## 4. 第三者提供
上記の外部サービス連携（RevenueCat・PostHog）を除き、利用者情報を第三者に提供することはありません（法令に基づく場合を除く）。
