# プライバシーポリシー（おしたくクエスト）

[English](privacy-en)

最終更新日：2026-10-23

本アプリ「おしたくクエスト」（以下「本アプリ」）は、以下の方針で利用者の情報を取り扱います。本アプリはお子さまが操作する画面を含むため、保護者の方に向けて、集める情報と使い道を具体的に記載します。

## 1. 収集する情報

### 端末内に保存される情報
- お子さまの名前・アイコン・テーマカラーなどのプロフィール情報
- 朝の支度タスクの設定内容（タスク名・絵文字・順番・有効/無効）、出発時刻
- タスクの完了状況と週のスタンプ
- 効果音・じゅんばんロックなどの設定、使われ方の記録を送るかどうかの回答

これらの情報は端末内にのみ保存され、当方のサーバーや外部サービスへは送信されません。**お子さまの名前、タスクの内容、お子さまの操作内容は、どの外部サービスにも送りません。**

### 外部サービスへ送信される情報

**PostHog（利用状況の分析）— 保護者が「協力する」を選んだ場合のみ**  
アプリの改善のため、PostHogを使って使われ方の記録を集めます。**初めて開いたときに保護者向けの画面で「協力する」を選んだ場合だけ送ります。** 「協力しない」を選んだ場合、または選ぶまでのあいだは、何も送りません。どちらを選んでも、すべての機能を使えます。送る情報は次のとおりです。
- アプリの起動・バックグラウンドへの移動・インストール・更新
- 保護者が行う操作（保護者設定を開いた、出発時刻を設定した、子どものプロフィールを追加した、課金画面を開いた、購入した）
- アプリのエラーの内容
- アプリの表示言語（日本語／英語）
- PostHogが自動で付ける情報（端末の種類、OSのバージョン、アプリのバージョンなど）
- PostHogが発行する匿名のID

インターネットの仕組み上、PostHogのサーバーにはIPアドレスなどが届きます。PostHogはIPアドレスから、おおよその地域（国・地域など）を推定することがあります。データは米国にあるPostHogのサーバーで処理されます。  
参考：<https://posthog.com/privacy>

**RevenueCat（アプリ内課金の管理）**  
ファミリーパック（買い切り）の購入と復元のため、RevenueCatを使います。RevenueCatは、購入の管理のために匿名のIDと購入履歴を扱います。この情報は購入の機能に必要なため、上の「協力する／協力しない」とは関係なく送られます。名前・メールアドレスは送りません。  
参考：<https://www.revenuecat.com/privacy/>

**Apple（App内課金）**  
ファミリーパックの決済はAppleのApp内課金を通じて行われます。支払い情報はAppleが管理し、当方は取得しません。  
参考：<https://www.apple.com/jp/legal/privacy/>

本アプリには広告がなく、広告のための情報の収集や、行動にもとづくターゲティングは行いません。

## 2. 利用目的
- アプリの不具合の調査と修正、アプリの改善のための利用状況の分析（PostHog）
- ファミリーパック（買い切り）の購入・復元の管理（RevenueCat）

上記以外の目的には使いません。

## 3. データの保管・削除・送信の停止
- 端末内のデータ（プロフィール・タスク・設定）は、アプリを削除すると端末から削除されます。
- PostHogに送った情報：
  - **保管期間**：PostHogのプランによります。現在は、送信から少なくとも1年間保管され、その後は削除されることがあります（プランの変更により変わることがあります）。
  - **送信の停止（同意の撤回）**：保護者設定（画面右上のアイコンを3秒長押し）の「使われ方の記録を送る」を、いつでもオフにできます（オンに戻すこともできます）。オフにすると、それ以降は送りません。端末に残る匿名のIDも消去します。
  - **削除**：送った情報は匿名のIDにのみ結びついており、名前やメールアドレスからは特定できません。そのため、通常は特定の方の情報だけを選んで削除することができません。削除をご希望の場合は下記の連絡先までご相談ください（端末のIDを当方から確認できないため、対応できる範囲に限りがあります）。
- 外部サービスが保持するデータは、各サービスのプライバシーポリシーにも従います。

## 4. 第三者提供
上記の外部サービス（PostHog・RevenueCat・Apple）を除き、利用者の情報を第三者に提供することはありません（法令に基づく場合を除く）。

## 5. 保護者の方へ
- 本アプリは、保護者の方が設定し、お子さまがタスクをタップして使うアプリです。使われ方の記録を送るかどうかは、保護者の方が選んでください。
- 送る情報の確認・送信の停止・削除のご相談は、下記の連絡先で受け付けます。
