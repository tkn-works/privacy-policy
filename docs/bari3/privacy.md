# プライバシーポリシー（バリ3）
最終更新日：2026-10-08

本アプリ「バリ3」（以下「本アプリ」）は、以下の方針で個人情報等を取り扱います。

## 1. 収集する情報

### 端末内に保存される情報
- 各ゲームのBEST記録・遊んだ回数
- アプリの起動回数・初めて起動してからの日数
- 効果音のオン/オフの設定

これらの情報は端末内にのみ保存され、当方のサーバーへは送信されません。

### 外部サービスへ送信される情報

**PostHog（利用状況分析）**  
アプリの改善を目的として、PostHogを使用してアプリ内の利用状況を収集します。**初めてアプリを開いたときの確認で「協力する」を選んだ場合にのみ**送信し、「協力しない」を選んだ場合は何も送信しません（どちらを選んでもすべてのゲームを遊べます）。収集する情報は以下のとおりです。
- アプリの起動・バックグラウンドへの移行などの基本的な動作
- ゲームの遊ばれ方（どのゲームを始めたか・終えたか・途中でやめたか、記録（スコア）、遊んだ秒数、新記録かどうか、終わり方、そのゲームを遊んだ回数、画面の描画の滑らかさ）
- 効果音のオン/オフの切り替え
- アプリの起動回数・初めて起動してからの日数
- アプリの不具合（エラー）の内容
- 端末の種類・OSのバージョン・アプリのバージョンなど、PostHogが自動で付ける情報
- PostHogが発行する匿名の識別子

氏名・メールアドレス・位置情報など、個人を直接特定できる情報は送信しません。  
通信の性質上、PostHogのサーバーには通信元のIPアドレス等が届きます。データはアメリカにあるPostHogのサーバーで取り扱われます。  
参考：<https://posthog.com/privacy>

本アプリには広告・アプリ内課金はなく、これらに関する情報は取得しません。

## 2. 利用目的
- アプリの機能改善・利用状況の分析（PostHog）
- 不具合の把握と修正

## 3. データの保管・削除・利用の停止
- 端末内のデータ（記録・設定）は、アプリを削除すると端末内のデータも削除されます。
- 外部サービス（PostHog）が保持するデータについては、次のとおりです。
  - **保持期間**: PostHogのプランで決まり、現在は送信から1年です（プランの変更で変わることがあります）。
  - **削除**: 送信されるデータは匿名の識別子に結びついていて、氏名やメールアドレスなどから個人を特定できません。そのため、特定の利用者のデータだけを選び出して削除することは、通常はできません。削除をご希望の場合は、下記のお問い合わせ先へご連絡ください。お使いの端末の識別子をこちらでは確認できないため、対応できる範囲は限られます。
  - **利用の停止（同意の撤回）**: ゲーム一覧の「記録の送信」の行で、いつでも「しない」に切り替えられます（「する」に戻すこともできます）。「しない」にすると、それ以降は何も送信しません。すでに送信済みのデータの削除は、上記のお問い合わせ先へご連絡ください。
- 外部サービス（PostHog）が保持するデータの扱いは、同社のプライバシーポリシーにも従います。

## 4. 第三者提供
上記の外部サービス連携（PostHog）を除き、利用者情報を第三者に提供することはありません（法令に基づく場合を除く）。
