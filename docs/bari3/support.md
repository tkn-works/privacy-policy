# サポート（バリ3）

## よくある質問

**音が出ません**
- 画面の左下の「音:ON/OFF」を押して、「音:ON」になっているか確認してください
- iPhoneの消音スイッチ・音量も確認してください

**BEST記録が消えました**
- 記録は端末内に保存されます。アプリを削除すると記録も削除されます

**操作が分かりません**
- ゲームの操作は、決定キー（真ん中のボタン）でスタートします。プレイ中は、どのキーでもジャンプなどの操作ができます
- 右のソフトキーで一時停止できます
